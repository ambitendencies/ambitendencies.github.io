# Signal Through Noise

Six-chapter personal site, based on the supplied brief. Concepts generated with the built-in image tool; filenames 01 through 06. UI remains native HTML and SVG. Raster images are archive artifacts and the quiet desk photograph, never whole-page screenshots.

## System

Charcoal #20211e, off-white #e7e4d9, rust #ce744b, muted #aaa99c, rule #41423a. DM Sans variable for display and body; Instrument Serif italic for emotional emphasis; IBM Plex Mono for navigation and small captions. Thin rules, square corners, restrained paper texture, generous fluid gutters. No neon, rounded card grids or decorative gradients.

Hero: BEN; Work, Writing, About, Contact; Signal through noise.; I build systems for messy problems.; Scroll to begin; 01 / THE LAG. All visible hero copy is locked to this list. Accessibility-only labels and a global motion control are functional additions.

Inventory uses an asymmetric archive composition. Compression uses a pinned reversible timeline with six geometry states: tabs, nodes, roots, circuits, print dots, final signal. Workbench uses expandable instrument rows. Human section uses a warm desk image alongside serif copy. Assembly repeats the mark and provides navigation.

## Implementation choices

GSAP ScrollTrigger owns scroll choreography and SVG paths. Motion owns reveal/accordion transitions. CSS owns the subtle cursor blink. All animations can be disabled; reduced-motion preferences use the fully assembled state and natural document scrolling. No synthetic audio or autoplay sound.

Content is adapted from the brief; portfolio descriptions are illustrative editorial copy, not claims of client work. Public contact and external article URLs require user-supplied values. Keep them in src/content.ts.
